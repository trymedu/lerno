# @medu/lerno-motion

Spring, keyframe, sequence, and stagger animation for Lerno. The API mirrors Motion's core
primitives while staying framework-free and deterministic.

## Install

```bash
bun add @medu/lerno @medu/lerno-motion
```

## Usage

```ts
import { spring, keyframes } from '@medu/lerno-motion';
```
